# TrailFrame

TrailFrame is an image discovery app that helps users explore visual inspiration by topic. This version fetches image results from the Wikimedia Commons API and displays them as responsive cards. I chose forest green and warm neutral colours to create a calm, nature-inspired look. I added quick-pick topic chips and clickable image cards to make exploring topics easier.

## Run locally
Open `index.html` in a browser with an internet connection. Search for `cats`, `ocean`, or `architecture`. The app uses the public Wikimedia Commons API and does not require an API key.
