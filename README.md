# TrailFrame — Visual Discovery

TrailFrame is a responsive image-search app built with plain HTML, CSS, and JavaScript. It uses the free Wikimedia Commons API and does not require an API key.

## Features
- Search by topic or use a quick-pick chip.
- Fetch and render image cards from Wikimedia Commons.
- Show a loading indicator while a search is in progress.
- Show a friendly message when no images are found or the request fails.
- Show a result count and link each card to the source image page.
- Responsive layout and subtle card animation.

## Run locally
Open `index.html` in a browser. Search requires an internet connection.

## Deploy with GitHub Pages
1. Push the project files to your public GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then click **Save**.
5. Wait for GitHub Pages to publish the site, then copy the live URL shown in Settings → Pages.

For Part 3, put both your repository URL and live URL in the pull request description.
